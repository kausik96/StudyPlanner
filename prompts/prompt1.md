## Step 1: A static React page

> Create a new React application using Vite and JavaScript in a folder named frontend. Replace the starter App.jsx with the simplest possible Study Planner component. Show a heading 'My Study Planner' and two hardcoded tasks: 'Math Homework' and 'Science Project'. Use only basic JSX. Do not use state, event handlers, APIs, CSS frameworks, or additional components yet. Explain every line in App.jsx, including the function, return statement, JSX, and export. Show how to run the app using npm run dev. Stop.
